# Plano de Estudos — Ciência de Dados

Site estático de acompanhamento de um plano de 12 semanas.

## Publicação
1. Crie um repositório no GitHub e envie `index.html` para a raiz da branch `main`.
2. Em **Settings → Pages**, selecione **Deploy from a branch**, `main`, `/ (root)` e salve (se disponível no seu plano).
3. Abra a URL publicada indicada em Pages.

## Progresso
As tarefas marcadas são armazenadas em `localStorage` no navegador, sob a chave `plano-estudos-v1`. Não há sincronização entre navegadores ou dispositivos. Limpar os dados do site pode apagar o progresso.

## Privacidade
GitHub Pages pode tornar o site acessível publicamente, mesmo quando o repositório é privado. Verifique as configurações e disponibilidade do seu plano.
